# 📊 গুগল শীট + অর্ডার সিস্টেম সম্পূর্ণ কানেকশন গাইড
### My Kid BD Shop — আয়ান ইন্টেলিজেন্স বুক

এই গাইড অনুসরণ করলে আপনার ওয়েবসাইটের অর্ডার ফর্ম থেকে সরাসরি Google Sheet-এ অর্ডার জমা হবে, এবং কাস্টমার নিজের অর্ডার ট্র্যাকও করতে পারবে। **কোনো কোডিং জ্ঞান লাগবে না — শুধু কপি-পেস্ট করলেই হবে।**

মোট সময় লাগবে: প্রায় ১০-১৫ মিনিট।

---

## ধাপ ১: নতুন Google Sheet তৈরি করুন

1. ব্রাউজারে যান: **https://sheets.google.com**
2. উপরের বাম দিকে **"+ Blank"** (নতুন খালি শীট) এ ক্লিক করুন
3. উপরে বাম কোণায় "Untitled spreadsheet" লেখাটায় ক্লিক করে নাম দিন: **`MKBD Orders`**

> ⚠️ শীটে ম্যানুয়ালি কোনো কলাম/হেডার বানানোর দরকার নেই — নিচের স্ক্রিপ্টটি প্রথম অর্ডার আসার সাথে সাথে স্বয়ংক্রিয়ভাবে "Orders" নামে একটা শীট এবং সব কলাম হেডার নিজেই তৈরি করে ফেলবে।

---

## ধাপ ২: Apps Script যুক্ত করুন

1. শীট খোলা অবস্থায় উপরের মেনু থেকে **Extensions (এক্সটেনশন)** → **Apps Script** এ ক্লিক করুন
2. একটা নতুন ট্যাবে Apps Script এডিটর খুলবে। ভেতরে আগে থেকে থাকা `function myFunction() {}` কোডটুকু **সম্পূর্ণ মুছে ফেলুন**
3. আমার দেওয়া `Code.gs` ফাইলের সম্পূর্ণ কোডটি **হুবহু কপি করে পেস্ট করুন**
4. উপরে প্রজেক্টের নাম "Untitled project" এ ক্লিক করে নাম দিন: **`MKBD Order API`**
5. **Ctrl+S** (বা 💾 Save আইকন) চেপে সেভ করুন

---

## ধাপ ৩: ওয়েব অ্যাপ হিসেবে Deploy করুন

1. উপরে ডান পাশে নীল **Deploy** বাটনে ক্লিক করুন → **New deployment** সিলেক্ট করুন
2. বাম পাশে ⚙️ গিয়ার আইকনে ক্লিক করে **Web app** সিলেক্ট করুন
3. এবার নিচের সেটিংসগুলো ঠিক এভাবে দিন:
   - **Description**: `MKBD Order API v1` (যেকোনো নাম দিতে পারেন)
   - **Execute as**: **Me (আপনার ইমেইল)**
   - **Who has access**: **Anyone** ⚠️ এটা অবশ্যই "Anyone" সিলেক্ট করতে হবে, নাহলে ওয়েবসাইট থেকে ডেটা পাঠানো/পড়া যাবে না
4. **Deploy** বাটনে ক্লিক করুন
5. গুগল একটা পারমিশন/অথোরাইজেশন চাইবে:
   - **Authorize access** ক্লিক করুন
   - আপনার গুগল অ্যাকাউন্ট সিলেক্ট করুন
   - "Google hasn't verified this app" মেসেজ আসলে **Advanced** → **Go to MKBD Order API (unsafe)** এ ক্লিক করুন (এটা আপনার নিজের স্ক্রিপ্ট বলেই এই সতর্কবার্তা আসে, এটা স্বাভাবিক ও নিরাপদ)
   - **Allow** এ ক্লিক করুন
6. Deploy হয়ে গেলে একটা **Web app URL** দেখাবে, যেমন:
   ```
   https://script.google.com/macros/s/AKfycbxxxxxxxxxxxxxxxxxxx/exec
   ```
7. এই URL টি **কপি করে নিরাপদ জায়গায় রাখুন** — এটাই আপনার ওয়েবসাইটে বসাতে হবে

---

## ধাপ ৪: ওয়েবসাইটে URL যুক্ত করুন

1. আপনার `index.html` ওয়েবসাইটটি ব্রাউজারে খুলুন
2. একদম নিচে ফুটারে ডান পাশে ছোট্ট ⚙️ (গিয়ার) আইকনে ক্লিক করুন
3. **"অ্যাডমিন কনফিগারেশন"** প্যানেল খুলবে
4. **Google Apps Script Web App URL** বক্সে ধাপ ৩-এ কপি করা URL টি পেস্ট করুন
5. **"সংরক্ষণ করুন"** বাটনে ক্লিক করুন
6. "✅ সংরক্ষিত হয়েছে!" মেসেজ দেখলে বুঝবেন সংযোগ সফল হয়েছে

> 💡 এই সেটিং শুধু ওই ব্রাউজারেই সেভ থাকে (localStorage)। ওয়েবসাইট যদি একাধিক ডিভাইস/ব্রাউজার থেকে চালান, প্রতিটাতে একবার করে এই ধাপ করতে হবে। হোস্টিং করার সময় চাইলে কোডে সরাসরি URL বসিয়েও রাখতে পারেন — বললে আমি সেভাবেও সেট করে দিতে পারি।

---

## ধাপ ৫: টেস্ট করুন

1. ওয়েবসাইটে ফিরে গিয়ে "অর্ডার করুন" ফর্মে টেস্ট নাম, ফোন নম্বর ও ঠিকানা দিয়ে একটা টেস্ট অর্ডার করুন
2. অর্ডার কনফার্মেশন মোডাল দেখানোর পর, আপনার Google Sheet-এ ফিরে যান
3. **Orders** নামে একটা নতুন শীট ট্যাব দেখতে পাবেন, এবং তাতে আপনার টেস্ট অর্ডারের সব তথ্য একটা সারিতে (row) যোগ হয়ে গেছে
4. যদি ডেটা না আসে:
   - Deploy সেটিংয়ে **"Who has access: Anyone"** ঠিক আছে কিনা আবার চেক করুন
   - ব্রাউজারের Developer Console (F12) খুলে কোনো Error আছে কিনা দেখুন
   - Apps Script এডিটরে **Executions** ট্যাবে গিয়ে চেক করুন রিকোয়েস্ট এসেছে কিনা এবং কোনো এরর হয়েছে কিনা

---

## ধাপ ৬: অর্ডার স্ট্যাটাস আপডেট করা (ট্র্যাকিং-এর জন্য)

কাস্টমার যখন "অর্ডার ট্র্যাকিং" থেকে তার অর্ডার আইডি বা ফোন নম্বর দিয়ে সার্চ করবে, তখন Google Sheet-এর **Status** কলাম (সর্বশেষ কলাম, N নম্বর) থেকেই বর্তমান অবস্থা দেখাবে। তাই অর্ডার প্রসেস করার সময় আপনাকে যা করতে হবে:

1. Google Sheet-এর **Orders** ট্যাবে যান
2. সংশ্লিষ্ট অর্ডারের সারিতে **Status** কলামে ক্লিক করুন (ড্রপডাউন আকারে থাকবে)
3. অবস্থা অনুযায়ী সিলেক্ট করুন:
   - `পেন্ডিং` — নতুন অর্ডার (ডিফল্ট)
   - `প্রসেসিং` — অর্ডার প্রস্তুত হচ্ছে
   - `শিপড` — কুরিয়ারে পাঠানো হয়েছে
   - `ডেলিভারড` — কাস্টমার বুঝে পেয়েছে
4. পরিবর্তন সাথে সাথেই সেভ হয়ে যাবে এবং কাস্টমার পরবর্তীবার ট্র্যাক করলে নতুন স্ট্যাটাস দেখতে পাবে

---

## ⚠️ গুরুত্বপূর্ণ নোট

- **কোড পরিবর্তন করলে**: ভবিষ্যতে যদি `Code.gs`-এ কোনো পরিবর্তন করেন, নতুন করে "New deployment" করবেন না — এতে URL বদলে যাবে। বরং **Deploy → Manage deployments → ✏️ (Edit) → Version: New version → Deploy** করুন, তাহলে আগের URL-ই বহাল থাকবে।
- **নিরাপত্তা**: "Anyone" অ্যাক্সেস মানে যে কেউ এই API URL জানলে তাত্ত্বিকভাবে ডেটা পাঠাতে পারবে। সাধারণ ছোট ব্যবসার জন্য এটা যথেষ্ট নিরাপদ, তবে URL টি পাবলিকলি শেয়ার করবেন না।
- **ব্যাকআপ**: এমনিতেও প্রতিটি অর্ডার ব্রাউজারের লোকাল ক্যাশেও (localStorage) সংরক্ষিত থাকে, তাই Google Sheet সাময়িকভাবে কানেক্ট না থাকলেও অর্ডার হারিয়ে যাবে না।
- **ফ্রি এবং সীমাহীন**: Google Apps Script সম্পূর্ণ বিনামূল্যে, তবে দৈনিক প্রায় ২০,০০০ রিকোয়েস্টের একটা কোটা আছে যা একটা ছোট/মাঝারি দোকানের জন্য যথেষ্টের চেয়ে বেশি।
